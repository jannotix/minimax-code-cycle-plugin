# Security policy

Cycle for MiniMax Code is in a pre-release production-hardening line. Do not include credentials,
private configuration, raw prompts, or private repository contents in an issue.

Report a suspected vulnerability privately to `giannotta@tublat.com`. Include the affected version,
the smallest reproducible case, impact, and any safe proof. You should receive an acknowledgement
within five business days. Coordinated disclosure is requested until a fix and release are ready.

Only the most recent published version is supported after the first production release. Until then,
the `2.0.0-alpha.*` line is not supported for production use and live MiniMax certification remains
a release gate.
